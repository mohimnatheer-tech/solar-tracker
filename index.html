لوح شمسي يلاحق الشمس بنفسه

مشروع Arduino يستخدم ثلاث مقاومات ضوئية ومحركين خطوييين ليدور اللوح ويميل حتى يواجه الشمس طول النهار. جرّب المحاكاة، وانسخ الكود، وابنه في البيت.

جرّب المحاكاة

محاكاة للوح الشمسي في الفيديو. ثلاث مقاومات ضوئية (LDR) تقيس الضوء، ومحركان خطوييان يدوران اللوح أفقياً وعمودياً حتى يواجه الشمس. حرّك الشمس بالسحب أو شغّل دورة يوم كامل.

القدرة الناتجة

طاقة المتتبعطاقة الثابت

الـ LDR الثلاثة مثبتة خلف اللوح بشكل مثلث وكل واحدة مائلة قليلاً عن الأخرى. إذا كانت الشمس أمام اللوح تماماً تعطي الثلاث قراءات متقاربة. إذا مالت الشمس إلى جهة تزيد قراءة المقاومة القريبة منها وتنقص الأخرى.

الكود يحسب اتجاه الخطأ من فرق القراءات، ثم يحرك المحرك الأول (قاعدة الدوران) للأفقي والمحرك الثاني (محور الميل) للعمودي إلى أن يقل الفرق عن حد صغير. عند الليل أو الغيوم الكثيفة تقل القراءات عن الحد الأدنى فيتوقف اللوح ولا يتحرك عبثاً.

سرعة الدوران في المحاكاة أسرع من الواقع، فمحرك 28BYJ-48 بطيء (حوالي 10 إلى 15 درجة بالثانية).

أجزاء مطبوعة 3D—القاعدة، الأعمدة، إطار اللوح، حامل الـ LDR
#include <Stepper.h>

const int STEPS = 2048;               // 28BYJ-48
Stepper pan(STEPS, 2, 4, 3, 5);
Stepper tilt(STEPS, 6, 8, 7, 9);

const int TOP = A0, LEFT = A1, RIGHT = A2;
const int MIN_LIGHT = 60;             // below this: night / heavy cloud
const int DEAD = 25;                  // dead band
int tiltPos = 0;                      // steps, limit 0..512 (0..90 deg)

void setup() {
  pan.setSpeed(10);
  tilt.setSpeed(10);
}

void loop() {
  int t = analogRead(TOP);
  int l = analogRead(LEFT);
  int r = analogRead(RIGHT);
  int sum = t + l + r;

  if (sum / 3 > MIN_LIGHT) {
    int ex = r - l;                   // horizontal error
    int ey = t - (l + r) / 2;         // vertical error

    if (abs(ex) > DEAD) pan.step(ex > 0 ? 4 : -4);

    if (abs(ey) > DEAD) {
      int d = ey > 0 ? 4 : -4;
      if (tiltPos + d >= 0 && tiltPos + d <= 512) {
        tilt.step(d);
        tiltPos += d;
      }
    }
  }
  delay(20);
}

خطوات البناء

  1. اطبع الأجزاءالقاعدة، العمود، إطار اللوح وحامل المقاومات الضوئية، بطابعة 3D.
  2. وصّل الإلكترونياتثبّت Arduino في القاعدة ووصّل لوحتي ULN2003 والمحركين حسب جدول التوصيل.
  3. ركّب الحساساتضع المقاومات الضوئية الثلاث بشكل مثلث خلف اللوح، كل واحدة مائلة لجهة، مع مقاومة 10kΩ لكل منها.
  4. اربط اللوح بالمحاورالمحرك الأول يدير القاعدة والثاني يميل اللوح. تأكد أن الأسلاك تتحمل الدوران.
  5. ارفع الكودانسخ الكود من الأعلى وارفعه بـ Arduino IDE، ثم عدّل حد الإضاءة وحد الخطأ حسب موقعك.
